# TG-ru

> **Сайт проекта:** [tg.24projects.ru](https://tg.24projects.ru/)

Публичный снимок исходников Android-клиента TG-ru. Здесь находятся изменения интерфейса и функций приложения, интеграция с Android и код транспортной библиотеки.

- `overlay/` — исходники и ресурсы Android-клиента.
- `native/` — патчи нативного сетевого слоя и инструкции по сборке.
- `tunnel/` — транспортная библиотека.
- `upstream-release.json` — версия базового клиента.

Android-код собирается поверх закреплённой версии upstream. Адреса в исходниках заменены на домен-пример. Для самостоятельного запуска требуется настроить свой сервер и подписать сборку своим ключом. Условия использования сторонних компонентов указаны в файлах лицензий и уведомлений.
